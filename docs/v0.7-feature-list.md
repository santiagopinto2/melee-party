# Melee Party v0.7 feature list

This list describes the private Windows test build. It separates implemented features from the
graphics work that is still missing, so the settings panel and test notes do not promise effects the
renderer cannot produce yet.

## Game and online play

- Native Windows x64 build of Melee NTSC 1.02, with the game logic translated from PowerPC to C++.
- D3D12 renderer and a D3D11 fallback.
- 60 Hz game simulation with monitor-rate, capped, or unlocked presentation; authored sub-frame
  animation between game frames.
- Slippi Ranked, Unranked, Direct-code, and Teams matchmaking, rollback netplay, chat, game reports,
  and `.slp` replay recording.
- Native practice preflight (experimental): Tab opens matchmaking in Training mode; gameplay continues through
  queueing and connection setup, then transitions to Slippi's online flow after both players are
  character-ready. Search can be cancelled, and a pre-match failure returns to the saved practice.
  Search cancellation, Direct first-match setup, and recovery after failure are supported.
- Discord Rich Presence and Join-code handoff. An accepted invite queues the sender's code for the
  next Online > Direct attempt; the local code is copied for the other player. The player still
  opens Direct and starts the attempt. Live Discord/peer testing remains outstanding.
- Memory-card saves in Dolphin `.gci` format.
- The launcher can keep published Windows versions in separate `Versions/` folders for rollback.
  Installed versions can be selected offline; the current install and shared player data remain
  available. A live older-version download/selection test is still pending.

## PC settings overlay

- Open with F1, Start + D-pad Down + Z, or PC Settings in Melee's Options menu. The optional Legacy Menu uses F11.
- Seven pages: Video, Audio, Game, Controls, Overlays, Customize, and Gecko Codes.
- Six persistent **Appearance** choices (new installs default to the pink **Clean side** menu).
  Customize shows a selectable image preview for each implemented appearance; the old UI is opened
  separately with F11 after enabling **Legacy Menu**:
  - **Clean side:** English slanted cards stack and slide over the live game, with no solid drawer
    backing. The title sits at the game's top-left edge while the cards stay on the right; Select,
    Back, and Categories share the same angled card treatment.
  - **Icon tiles:** rounded, shaded icon buttons with a visible bevel, rim, and lower body,
    inspired by the Smash 4 / Ultimate menus.
  - **GD's Melee:** its attributed sheared navigation rows and classic gold palette. The actual 60 Hz slide-in
    and slide-out keyframes are ported into the settings panel and sampled at the current render
    rate, including 120 Hz and 144 Hz presentation; the full native GD Melee frontend is not a
    drop-in replacement for this static-recompilation renderer.
  - **Radial:** a seven-category wheel with a recessed center, shaded sectors, and raised rim
    over the live game, plus a separate spacious settings page for each category.
  - **Wide tabs:** a compact header with category tabs only; choosing a tab opens its real settings page.
- **Simple:** the compact, low-decoration settings layout.
- The optional **Legacy Menu** opens with F11 after its Customize checkbox is enabled. It restores
  the compact v0.6.6 settings presentation, with Lucida Console text and the original blue and purple
  controls, and reads and writes the same setting values as the modern menu.
- These appearances are saved with their own navigation structures. Their visual
  match to all reference mockups, the imported GD frontend's full interactions, and the high-refresh
  motion pass are still incomplete; they are not being described as a finished exact port.
- Each appearance has four independent saved color palettes. GD Melee offers Classic Gold, Cobalt,
  Emerald, and Crimson; the other layouts have palettes fitted to their own shapes and accents.
- Responsive layouts, keyboard/controller navigation, saved settings, and restart notices when a
  change needs a restart.

## Video and display

- Quality presets, EFB/internal-resolution scaling up to 8x, 4x SSAA, anisotropic filtering,
  sharpening, brightness, contrast, and vibrance.
- NVIDIA DLSS/DLAA and Streamline Frame Generation modes reported by the installed GPU and driver
  (including RTX 50-series 5x/6x modes when exposed); Intel XeSS modes; NVIDIA Reflex and latency
  readout. 2x, 6x, and Dynamic Frame Generation have been verified in focused local two-client
  Unranked matches on the RTX 5070; fixed 3x–5x modes have not been individually verified.
- Optional screen-space ambient occlusion uses the reversed-depth buffer on both D3D11 and D3D12.
  It is an experimental contact-shading approximation, disabled by default, and still needs a visual
  quality pass across stages.
- Optional experimental DLSS 5 neural-rendering path. Its NVIDIA model/runtime is supplied by the
  NVIDIA installation and is not redistributed in this test archive. The experimental build has
  0–1000% intensity, surface-detail, lighting/tone, and manual skin-detail controls. Values above
  200% are passed to the model but NVIDIA has not published a supported numeric range for them;
  successful rendering at the extreme settings is not yet verified.
- VSync, window-size presets, borderless/exclusive fullscreen, aspect-ratio controls, Slippi
  widescreen, and experimental renderer-side true 16:9.
- H.264 looping character-select and stage-select video backgrounds, learned target matching, and
  vanilla-background fallback if a video or target fails.
- Fountain of Dreams reflections enabled by default, with an optional Lagless FoD mode.
- Low-spec preset that lowers graphics cost while keeping game simulation behavior unchanged.

## Game, overlays, and accessibility

- Stock-icon and damage-number size controls, saved across restarts.
- Optional player nicknames above fighters, using Melee's player-tag positions.
- Optional PAL-style stock icons, L-cancel indicator and helper, no-screen-shake option, online
  delay control, frame-rate/ping/performance overlays, and customizable controller input overlay.
- Player-tag alignment for every online slot has not been verified in a live four-player match.

## Controls

- GameCube adapter, keyboard, Xbox/XInput, Switch Pro, and experimental DualShock 4 input support.
- Controller rebinding, per-device profiles, port assignment, and calibration. Controls has a
  saved Controller rumble switch for GameCube adapters and Xbox pads; switching it off stops
  active motors immediately, including during online play.
- GameCube adapter polling-rate readout based on actual received reports.
- Adapter startup follows the Wii U-mode `SET_PROTOCOL`, report-start `0x13`, and all-off rumble
  `0x11` sequence. Physical adapter validation still needs to be repeated on the test package.

## Customize and cosmetics

- Import costume and stage DAT files, ZIP mods, and Nucleus vault archives.
- Stage resources map to their matching disc files. Pokémon Stadium handles `GrPs.dat` and
  `GrPs1.dat`–`GrPs4.dat` separately; invalid or empty stage choices are hidden.
- Move-level cosmetic effect slots allow compatible Fox effect changes to compose. Overlapping
  edits report a conflict.
- Imported previews and selected/active state appear in Customize; changes show restart notices.
- Online stage DATs are enabled only when exact-ISO validation proves visual-only behavior; unsafe
  stage changes use vanilla resources online.
- Validation covered the supplied vault, Tom Nook, Patched Plains Dream Land, and Fox effects.

## Experimental graphics work

- D3D12 DXR hybrid diffuse path tracing and DLSS Ray Reconstruction are implemented behind opt-in
  settings. The pass uses one sample per pixel and three diffuse bounces, with Melee's raster image
  supplying direct lighting and material color. RR receives the HDR output, depth, motion vectors,
  diffuse and specular albedo, and packed normal/roughness guides. It was exercised on an RTX 5070,
  but final image quality and sustained performance are still under validation; this is not a full
  replacement for Melee's GX lighting/material renderer.
- Battle Arena waiting rooms and audio-reactive wallpapers remain future work.
- Akaneia, 20XX, and UnclePunch compatibility remains under investigation for v0.75/0.8. Their
  altered game code and data have not been shown to preserve Slippi's online simulation here;
  v0.7 does not claim safe online play with those modded game builds.
