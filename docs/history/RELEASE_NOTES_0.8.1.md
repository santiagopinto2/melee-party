# Melee Unlocked 0.8.1

Fixes for the Source Port.

## Install

Download the Windows archive from the release page:

- `MeleeUnlocked-0.8.1-win64.zip`: the one build for everyone. It includes both game builds.

Close Melee Unlocked, then extract the archive over your existing game folder, or use the launcher's Update button. Your settings, saves, and replays carry over. Keep your own Melee NTSC 1.02 ISO beside the game files as `melee.iso`, or select it with the included launcher.

## Fixes

- Fixed the crash or freeze going into the second online game, in Unranked and Direct.
- Fixed a crash after a match ends.
- 1P Classic, Adventure and All-Star work on the Source Port: fixed crashes on picking the mode and on the Stage Clear screen.
- Fixed the game closing on the Rumble screen, and crashes on the Erase Data, VS Records and Data > Info screens.
- Rumble follows the Controller rumble setting again, online only your own controller rumbles, and replays no longer rumble.
- Event Match works on the Source Port.
- Fixed a crash when a fighter touches Brinstar's lava and other stage hazards.
- Replay Viewer: stats headers no longer cut off.

## Notes

- If something crashes, please send the melee_port_crash files from your game folder.
