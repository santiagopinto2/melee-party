# Melee Unlocked 0.7.1

Hotfix for Slippi widescreen and quitting with Esc.

## Install

Download the Windows archive from the release page:

- `MeleeUnlocked-0.7.1-win64.zip`: the one build for everyone, with optional experimental DLSS 5 and a compatibility version the launcher picks automatically on older CPUs. DLSS 5 needs NVIDIA's DLSS 5 file, which is not included.

Close Melee Unlocked, then extract the archive over your existing game folder, or use the launcher's Update button. Your settings, saves, and replays carry over. Keep your own Melee NTSC 1.02 ISO beside the game files as `melee.iso`, or select it with the included launcher. Start the included `MeleeUnlockedLauncher.exe` after extraction.

## Fixed

- Slippi Widescreen 16:9 no longer smears the picture into horizontal streaks.
- Esc can quit the game again: Esc opens settings, Esc on the category screen asks to quit, Enter quits and Esc cancels. On a settings page, Esc goes back to the categories.

## Notes

- If Unranked crashes for you, please send `melee_port_crash.txt` and `melee_port.log` from your game folder.
